# results/records/

Run records written by the estimation scripts when they are run from this
archive: truth-check (S0) records and attempt logs of the simulation study,
coverage-precheck aggregates, and the attempt logs of the single-run scripts
(`run_k2.py`, `run_k2br.py`, `run_expi_*.py`, `k1_guard_sensitivity.py`).
`run_k2br.py` also accepts free-form run notes in `k2br_run_notes.md` here
(a file allowed to change after the code commit). The archive ships none of
these records; the records of the analysis reported in the paper are part
of the authors' private version-controlled record.
